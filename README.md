# cups-server-docker
A small, purpose-built CUPS image for sharing a USB printer over the network from a Debian 12 host, using driverless IPP-over-USB (ipp-usb) instead of a vendor driver.  Built and verified end-to-end against a Brother DCP-T220 on an OpenMediaVault (Debian 12) NAS, but see Compatibility below — nothing here is actually Brother-specific.
